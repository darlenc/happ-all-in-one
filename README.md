# Happ ALL-IN-ONE

Одна **публичная подписка для Happ**, собираемая из нескольких независимых открытых источников. GitHub Actions пересобирает список до 100 конфигураций каждые 6 часов. Никакой аренды VPS или платных ключей.

## Ссылка для Happ

```text
https://raw.githubusercontent.com/darlenc/happ-all-in-one/main/happ-all.txt
```

Скопируйте ссылку → откройте **Happ** → **+** → **Добавить подписку** → вставьте URL. Не импортируйте файл `build.py` или ZIP в Happ.

В Happ желательно включить:
- **Настройки → Подписки → Ping on Launch** («Пинг при запуске»).
- Тип проверки **Via Proxy** (GET или HEAD), если доступен: это информативнее, чем обычный TCP ping.
- Автоматическое обновление подписок.

После этого нажмите на значок спидометра у подписки и проверьте серверы. Выбирайте узлы, у которых проверка проходит, и попробуйте открыть нужный сайт. Если текущий сервер перестал работать, переключитесь на другой из того же списка.

**Внимание:** подписка собирает все узлы в один список, но сама по себе **не обеспечивает бесшовное переключение при обрыве**. Поиск или смена сервера в Happ — отдельная настройка и зависит от версии приложения.

## Что делает сборщик

- Загружает публичные конфигурации из 5 источников (перечислены в `build.py`).
- Оставляет VLESS с TLS/Reality, Trojan с TLS и Hysteria2.
- Убирает синтаксически неправильные адреса, явно небезопасные параметры `insecure=1`, локальные IP, дубли конечных точек.
- Ограничивает повторения из одной подсети и с одним SNI; по очереди берёт узлы из разных источников.
- Записывает `happ-all.txt` и статистику `status.json`.
- Если доступно слишком мало записей, не затирает прежнюю подписку.

**Фильтрация не равна проверке работоспособности.** GitHub Actions находится в другой сети: подключение из России/Новосибирска, доверие к владельцам серверов, скорость и отсутствие блокировок этим проектом не подтверждаются. Узлы нескольких IP могут всё равно принадлежать одному оператору.

## Обновление

Откройте **Actions → Refresh Happ VPN pool → Run workflow** для внеочередного обновления.

Автоматическое расписание: каждые 6 часов (GitHub может запускать запланированные задачи с задержкой). Если GitHub Actions не сможет загрузить источники, сборка завершится ошибкой, а последний опубликованный список останется на месте.

Статистика: [status.json](./status.json). История обновлений: [GitHub Actions](./actions).

## Безопасность

Списки содержат **чужие публичные серверы**, а не доверенный собственный VPN. Не используйте их для банков, Госуслуг, финансовых операций, рабочих секретов или важных учётных записей. Не устанавливайте сторонние корневые сертификаты и не отключайте проверку HTTPS/TLS. HTTPS защищает содержимое соединений, но владелец VPN способен наблюдать часть метаданных и контролировать свой прокси.

Репозиторий публичный — не добавляйте сюда личные платные ключи, пароли или приватные ссылки-подписки.

## Разработка и проверки

Python 3.12+, без внешних зависимостей:

```bash
python build.py --limit 100 --out happ-all.txt
```

Проект не связан с разработчиками Happ. Он не продаёт и не предоставляет VPN-серверы, а публикует каталог уже открытых конфигураций.
